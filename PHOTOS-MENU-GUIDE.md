## 🔍 VALIDATION DES PHOTOS

Le script vérifie automatiquement :

✅ **Existence** : Le fichier existe
✅ **Extension** : .jpg, .jpeg, .png, .webp
✅ **Taille min** : > 1 KB (pas de fichier vide)
✅ **Taille max** : < 10 MB
✅ **Nom** : Correspond exactement au manifest

❌ **Rejets** :
- Fichiers vides (0 bytes)
- Extensions invalides (.gif, .bmp, .svg...)
- Fichiers trop grands (> 10 MB)
- Noms incorrects

---

## 📊 RAPPORT APRÈS UPLOAD

Le fichier `menu-images/upload-report.json` contient pour chaque plat :

```json
{
  "menuItemId": "...",
  "name": "Pizza Margherita",
  "expectedFile": "pizza-margherita.jpg",
  "status": "SUCCESS",
  "cloudinaryUrl": "https://res.cloudinary.com/..."
}
```

**Statuts possibles** :
- `SUCCESS` : Photo uploadée et MongoDB mis à jour ✅
- `MISSING` : Fichier introuvable ❌
- `INVALID` : Fichier invalide (taille, extension) ⚠️
- `UPLOAD_FAILED` : Échec upload Cloudinary ❌
- `UPDATE_FAILED` : Échec mise à jour MongoDB ❌

---

## 🚨 DÉPANNAGE

### Problème : "Fichier introuvable"
**Solution** : Vérifiez le nom exact du fichier (casse, tirets, extension)

### Problème : "Extension invalide"
**Solution** : Utilisez .jpg, .jpeg, .png ou .webp uniquement

### Problème : "Fichier trop grand"
**Solution** : Compressez l'image à < 10 MB

### Problème : "Upload Cloudinary échoué"
**Solution** : Vérifiez la configuration Cloudinary dans `backend/.env`

### Problème : "Plat introuvable dans MongoDB"
**Solution** : Réexécutez `npm run menu:audit` pour vérifier l'ID
