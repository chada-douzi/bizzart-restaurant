🎯 Root Cause Analysis

Technical Explanation

MongoDB Atlas uses SRV records (_mongodb._tcp.cluster0.fhtq6yf.mongodb.net) for cluster discovery when using mongodb+srv:// URIs.

Without explicit DNS server configuration, Node.js relies on the Windows system DNS, which may not reliably resolve SRV records, especially in certain network configurations.

By setting DNS servers to 8.8.8.8 (Google) and 1.1.1.1 (Cloudflare), audit:indexes ensures proper SRV record resolution, while audit:relevance fails due to Windows DNS limitations.

Why It Matters

mongodb+srv:// URIs: Require DNS SRV record resolution
Windows System DNS: May not reliably resolve SRV records
Google DNS (8.8.8.8): Known to handle SRV records correctly
Node.js Behavior: Uses system DNS unless explicitly configured
