**Style unifié pour toutes les images:**

- Lumière naturelle douce
- Angle 3/4 légèrement au-dessus

- Arrière-plan sobre légèrement flou
- Profondeur de champ naturelle
- Textures alimentaires réalistes

- Style moderne restaurant premium
- **Aucun texte, logo, watermark, personne, publicité**

**IMPORTANT:** La vaisselle doit être adaptée naturellement:
- Assiette pour plats solides (pizzas, viandes, volailles)
- Bol pour pâtes, salades, paella
- Verre pour boissons
- Pas d'assiette blanche imposée systématiquement

## 🔧 GÉNÉRATION DES IMAGES

### Options de Générateur IA

#### Option A: DALL-E 3 (Recommandé)
- **Qualité:** Excellente pour photographie culinaire
- **Coût:** ~$0.04 par image 1024x1024
- **Total:** 10 images × $0.04 = **$0.40**
- **Méthode:** API OpenAI ou interface ChatGPT Plus

#### Option B: Midjourney
- **Qualité:** Très haute qualité artistique
- **Coût:** Abonnement mensuel requis
- **Méthode:** Discord bot (workflow manuel)

#### Option C: Stable Diffusion
- **Qualité:** Variable selon le modèle
- **Coût:** Gratuit (local) ou peu coûteux
- **Méthode:** Installation locale ou services cloud

### Étapes de Génération

1. **Choisir le générateur IA** (DALL-E 3 recommandé pour ce projet)
2. **Générer les 10 images** en utilisant les prompts ci-dessus
3. **Télécharger les images** générées
4. **Sauvegarder** avec les filenames spécifiés
5. **Évaluer la qualité** de chaque image

## 📊 CRITÈRES D'ÉVALUATION

Pour chaque image générée, vérifier:

| Critère | Description |
|---------|-------------|
| **Correspondance plat** | L'image représente-t-elle bien le plat nommé? |
| **Ingrédients visibles** | Les ingrédients mentionnés sont-ils visibles? |
| **Qualité photoréaliste** | L'image semble-t-elle être une vraie photo? |
| **Cadrage** | Angle 3/4, centré, bien composé? |
| **Éclairage** | Lumière naturelle douce? |
| **Présentation** | Élégante et appétissante? |
| **Vaisselle** | Adaptée au type de plat? |
| **Arrière-plan** | Sobre et légèrement flou? |
| **Absence éléments interdits** | Pas de texte, logo, watermark, personne? |
| **Artefacts IA** | Pas de déformations ou éléments bizarres? |
| **Cohérence style** | Cohérent avec les autres images? |

**Échelle d'évaluation:**
- ✅ **EXCELLENT** (9-10/10): Prêt pour utilisation
- ⚠️ **BON** (7-8/10): Acceptable, petits ajustements possibles
- ❌ **INSUFFISANT** (<7/10): Regénération nécessaire
